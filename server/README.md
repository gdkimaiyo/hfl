# HFL API Service

The APIs for the HFL app

## Setting up Project

Set up environment variables according to `env.sample`

#### `yarn install`

Install the packages/dependencies.

#### `yarn start:dev`

Runs the app in development mode.Open [http://localhost:5002](http://localhost:5002) to view api in the browser.

#### `yarn test`

Run application tests.

#### `yarn lint`

Check for linting errors.
